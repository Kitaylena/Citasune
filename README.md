# Citasune 🦊✨

Welcome to the official repository for **Citasune**, a passion-project Unblocked Games (UBG) site crafted with care!

---

## 🚀 Future Ideas & Feature Roadmap

If you want to spice up this repository and make the site feel even more alive, consider adding some of these cool visual and interactive elements:

### 🎨 Visuals & Aesthetics
* **Custom Banners & Artwork:** Add a signature header logo or pixel-art icons for navigation categories to give it an arcade-style vibe.
* **Dynamic Themes:** Implement a theme toggle (Dark Mode, Retro Arcade, Vaporwave) using CSS variables.
* **Interactive Game Cards:** Use CSS hover effects so game tiles smoothly lift, drop shadows, or display animated previews/GIFs.

### ⚡ Quality-of-Life Features
* **"Surprise Me" Button:** A random game selector for when visitors can't decide what to play.
* **Favorites System:** Leverage browser `localStorage` to let users heart games and save them to a local favorites tab.
* **Recently Played History:** Automatically track the last few played games for quick access.
* **Real-time Search & Tags:** Instant filtering by genre (*Action, Puzzle, Retro, Multiplayer*).

### 🕹️ Fun Extras
* **Changelog Modal:** A "What's New" popup to showcase newly added games and site updates.
* **Secret Easter Eggs:** Add hidden keyboard shortcuts that trigger fun visual effects or sound bites.
* **Custom Loading Screens:** Stylized progress bars with pixel art or witty loading tips for heavier games.
